# Future OS Lab

Ten operating-system layout concepts drawn from VR subreddits, developer forums and science fiction, each previewed on an IT workstation, a car dashboard and a phone. The Build tab lets you remix any layout or create a new one, save it in your browser, and share it as JSON.

Live: https://joehillthunder.github.io/displayxr-future-os/

Part of [DisplayXR HQ](https://joehillthunder.github.io/) (Spatial UI/UX wing).

- Single static `index.html`, no build step, no keys.
- Runs in 2D in any browser.
- Saved layouts live in the viewer's `localStorage`; use Share as JSON to back them up.
